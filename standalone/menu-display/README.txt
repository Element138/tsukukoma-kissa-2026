喫茶 メニュー表示 — Windows x64

1. ZIPをすべて展開し、書き込み可能なフォルダーに置いてください。
2. Start-Menu.cmd を開くと、ローカルサーバーと全画面のEdgeが起動します。
3. 画面コントローラーには http://127.0.0.1:8787/ を設定してください。
   コントローラーを使う場合は Start-Server.cmd でサーバーのみ起動できます。
4. 終了するときはEdgeを閉じ、Stop-Menu.cmd を開いてください。

インストール・ログインは不要です。ロゴ・フォント・初期メニューは同梱しています。
起動・再読み込み時および約30秒ごとに更新を試みます。更新できなくても保存済みの
メニューを表示します。画像を含めた更新が完了してから保存内容を切り替えます。
オフラインでは在庫・待ち時間などは最後に取得した状態です。
保存済みのラストオーダー時刻はJSTで動作します。PCの日時は正しく設定してください。

cache フォルダーは最後に正常取得した内容です。削除しないでください。
設定は config.json、接続状態は http://127.0.0.1:8787/health で確認できます。
ポート8787が他のアプリで使われている場合は config.json の port を変更してください。
初期HTMLは index.html です。直接開く代わりに、上記ローカルURLを使用してください。
オンライン更新は、対応するWebアプリの本番リリース後に有効になります。
